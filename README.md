# DB Lab – Multi-Database Platform

A practical database learning platform integrating **MySQL, PostgreSQL, MongoDB, and Apache Cassandra** through a unified UI.

* Execute database queries and CRUD operations through an interactive interface.
* Explore SQL and NoSQL concepts in one application.
* Understand database APIs, data modeling, and application integration.
* Built with **Python, Streamlit, Docker, and database connectors**.
* Designed to demonstrate how multiple databases can work together in a production-oriented application.

**Goal:** Learn, experiment, and understand multiple database technologies from a single platform.
